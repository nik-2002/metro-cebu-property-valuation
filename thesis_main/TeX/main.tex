\begin{abstract}
This study focuses on the residential real estate market within Cebu City and selected component cities of Metro Cebu. It aims to develop a data-driven property valuation model using a hybrid dataset of foreclosed verified floor prices and online market ceiling prices harvested via automated web scraping. The study compares Hedonic Regression with Machine Learning approaches (Random Forest, XGBoost) enriched with GIS-derived spatial features to identify key determinants of value, including the impact of future infrastructure like the Cebu Bus Rapid Transit (CBRT).
\end{abstract}
