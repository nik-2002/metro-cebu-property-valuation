# Nighttime Lights Revisited: The Use of Nighttime Lights Data as a Proxy for Economic Variables

## 1. Key Quantitative Findings
- **The Warning**:
    - **Elasticity**: Growth elasticities are **"Low and Unstable."**
    - **Explanatory Power**: **"Little explanatory power"** for GDP, Manufacturing, or Capital Stocks.
- **The Exception**:
    - **Electricity Consumption**: Lights *are* a good proxy for Electricity Consumption, but only at **10-year intervals** (Long term).
- **Data Quality**: Explicitly characterized DMSP data as **"Quite Noisy."**

## 2. Thesis Utility: "The Cebu Model"
*Relevance to Data-Driven Real Estate Valuation:*
- **Application**: **WARNING/Counter-Argument**. If you plan to use Nighttime Lights as a feature, **you must cite this paper** as a "Cautionary Tale" in your Limitations. It suggests Lights might not correlate well with granular Year-over-Year price changes.
- **Relevance**: Prevents you from blindly trusting a popular proxy. You might need to use newer data (Suomi NPP/VIIRS) instead of the older DMSP data analyzed here.
- **Theoretical Framework**: **Proxy Variable Validity**.

## 3. Methodology
- **Analysis**: Regressed Nighttime Light intensity against various economic indicators (GDP, Pop, Manufacturing).
- **Data**: DMSP (Defense Meteorological Satellite Program).

## 4. Limitations & Future Research
- **Constraints**: Study used older **DMSP** data (prone to saturation/blooming).
